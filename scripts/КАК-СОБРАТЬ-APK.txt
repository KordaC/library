Как раздать приложение: «скачал APK — всё работает» (Wi‑Fi и мобильный интернет)
================================================================================

На телефоне НЕ нужны ngrok, Tailscale и настройка адреса — только ваш APK.
Сервер должен быть в интернете 24/7 (один раз настраиваете вы).

ШАГ 1. Backend в облаке (Render.com, бесплатно)
-----------------------------------------------
1. Залейте проект на GitHub (или GitLab).
2. Зарегистрируйтесь на https://render.com
3. New → Blueprint → выберите репозиторий (файл render.yaml в корне).
4. Дождитесь деплоя. Скопируйте URL сервиса, например:
   https://library-backend-abcd.onrender.com

5. В Render → Environment добавьте (если QR не открывается с телефона):
   LIBRARY_PUBLIC_BASE_URL = https://library-backend-abcd.onrender.com

Первый запрос после «сна» сервера может идти 30–60 сек.

ШАГ 2. Собрать APK с этим адресом
---------------------------------
В файле local.properties (корень проекта) добавьте:

backend.url=https://library-backend-abcd.onrender.com/api/v1/

(подставьте свой URL из Render)

Android Studio: Build → Generate Signed Bundle / APK → APK → release
или: .\gradlew.bat :app:assembleRelease

ШАГ 3. Установить APK на телефон
--------------------------------
Передайте файл app-release.apk — установить — войти 20001 / Demo1234.

Поле «адрес сервера» в release-сборке скрыто: адрес уже внутри APK.

Разработка у себя (эмулятор / Wi‑Fi)
------------------------------------
backend.host=10.0.2.2  или  192.168.x.x
Собирайте debug, не release.
